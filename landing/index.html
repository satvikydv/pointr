You decide how much it can do on its own

Pointr can type into a focused field or open an app for you. By default it shows exactly what it's about to do and waits for Enter - or switch to Always allow in Settings and it just gets on with it, Esc still stops any run.

05
05 - VOICE FLOWS

Hold a key, speak, let go

Hold Ctrl + Win and say what you want - Pointr transcribes it on your own computer as you talk and sends it the instant you release, exactly like typing. Say "agent" or "explain" first to use those modes, or just address it as "Pointr". Your voice never leaves your machine unless you choose otherwise.

Changelog

v0.2.0 currently live
v0.2.0 Sep 2026 Live
  • OpenAI support alongside Gemini - connect either key, or both, and switch anytime in Settings.
  • Pick any model your key can use, not just the shipped default - live model list plus a custom model ID box.
  • Both providers are bring-your-own-key - no shared fallback key, no request ever runs on someone else's account.
  • Opt-in anonymous usage telemetry, off by default - see the new Privacy page.
  • Backend retention hardening - shorter result expiry, rotated logs, no on-disk persistence.
v0.1.1 Aug 2026
  • Custom app and tray icon - no more the default Tauri logo.
  • Redesigned Settings panel - pinned Save/Test footer, no more scrolling to find it.
  • Startup splash screen confirms Pointr is running the moment you launch it.
  • Lightweight update check - you'll get a prompt when a newer version is out.
v0.1.0 Aug 2026
  • First public Windows installer - download and run, no build step required.
  • Bring your own Gemini API key in Settings - nothing shared, nothing metered on our end.
  • Agent tasks can now search the live web and read your GitHub repos, issues, and pull requests.
v0.0.5 Aug 2026
  • Action confirm prompts for typing into fields and opening apps, confirmed with Enter, cancelled with Esc.
  • Unified the glass-panel header pattern across the answer, storyboard, and action-confirm surfaces.
v0.0.4 Jul 2026
  • Storyboard explanation mode via "explain: <topic>" - narrated steps with on-screen point, box, and arrow annotations.
  • Auto-advancing captions with progress dots and a one-time "Esc to stop" hint.
v0.0.3 Jun 2026
  • Region-select ask flow - draw a box, ask about exactly what's inside it.
  • Full error-state coverage across every entry point.
v0.0.2 May 2026
  • Rebuilt the voice indicator as a glass-and-plasma energy sphere.
  • Smooth cross-fade between the idle dot and the active sphere.
v0.0.1 Apr 2026
  • Initial overlay: direct-ask input, loading states, answer bubbles.
